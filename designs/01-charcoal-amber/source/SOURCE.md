# 制作材料与来源

本目录包含可继续修改的位图底图、独立胸标、参数与提示词；尚无 PSD、AI、SVG 等分层设计工程。

| 文件 | 内容与来源 |
| --- | --- |
| `base.png` | 原“配色修正 v8”工作目录中的无胸标底图，RGB 像素与当前方案预览一致 |
| `lion-v6.png` | 已修订比例的 v6 攻城狮透明胸标，原文件直接复制 |
| `composition.json` | 可编辑合成参数；默认关闭胸标，保持当前无胸标方案 |
| `PROMPTS.md` | 内置 image_gen 的历史配色与胸标清除提示词 |

[统一合成脚本](../../../scripts/render-design.ps1) 根据原 `composite-v6.ps1` 的缩放与叠加逻辑整理，使用仓库相对路径。原脚本的局部清除旧胸标阶段已体现在底图中，继续添加新胸标时无需再执行。

底图包含衣服、文字、纹样和背景的完整平面画面；这些元素尚未独立分层。可在图片编辑软件中以底图建立新工程，或使用提示词继续编辑，再提供新的源文件。

原始素材来自本地队服设计记录，具体作者署名及素材使用范围待团队确认。此目录记录来源，不新增授权声明。

操作步骤见[修改指南](../../../docs/EDITING.md)。
