## 设计想法

白色圆领与主体搭配浅蓝色代码碎片，在正面图像右侧形成由密到疏的纹样，并组成侧向 `EECS`。背面使用浅蓝色 `PKU EECS` 与 `PLAYER NAME`，代码纹样呼应正面。

可以继续探索代码纹样的疏密和可读性、侧向字形、胸标位置与印花对比度。微小字符目前是概念纹理，并非已校对的代码或生产稿。
