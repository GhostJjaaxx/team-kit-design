## 设计想法

以奶油白为主色，酒红用于 V 领、肩线、侧身与电路纹样，搭配少量灰色线条。正面胸部留白，背面以酒红呈现 `PKU EECS` 和 `PLAYER NAME`。

可以继续探索胸标方案、酒红色深浅、浅色面料呈现效果和背面文字比例。图中姓名为占位，最终印制内容另定。


##本次优化

在保留原方案奶油白与酒红配色的基础上，进一步融入北大校园文化与信科元素，将电路纹理与羽毛球运动轨迹相结合，突出科技感与运动感。
优化图案布局与配色比例，减少过于密集的装饰，使球衣整体更加简洁、协调，同时考虑实际穿着效果和批量制作难度。
